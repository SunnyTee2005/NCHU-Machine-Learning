選擇為什麼不能直接用 test set 來挑 hyperparameter？

  1. test set 通常太小
  2. 會變成對 test set overfit，test 分數過度樂觀，不能代表真正的 generalization
  3. test set 沒有 label
  4. 訓練會變慢
看答案

B。用 validation set 挑 hyperparameter，test set 只在最後用一次。

p.11–16

簡答說明 K-fold cross validation 的做法和用意。

看答案
  • 做法：把 training data 切成 K 份，輪流拿 1 份當 validation、其他 K−1 份訓練，跑 K 次後取平均分數。
  • 用意：只切一次的話結果看運氣（p.22 的 unrepresentative samples），K-fold 讓每筆資料都當過驗證資料，評估比較穩定。
  • 缺點：要訓練 K 次，比較花時間。

p.22–23

計算COVID 檢測：TP = 70、FP = 30、FN = 20、TN = 60。求 precision、recall、F1。

看答案

Precision = 70 / (70+30) = 0.70

Recall = 70 / (70+20) ≈ 0.78

F1 = 2·P·R / (P+R) = 2×0.7×0.778 / 1.478 ≈ 0.74

p.57–62

選擇資料中只有 10% 是「5」。一個模型把所有圖片都猜成「不是 5」，它的 accuracy、precision、recall 大約是？

  2. 90%、90%、0%
  3. 90%、0%、0%
  4. 0%、0%、0%

計算＋簡答MNIST 有 10 類。用 OvR 和 OvO 各要訓練幾個二元分類器？為什麼 SVM 通常偏好 OvO？

p.48–49

計算P(N)=0.6、P(Dear|N)=0.47、P(Friend|N)=0.29；P(S)=0.4、P(Dear|S)=0.29、P(Friend|S)=0.14。訊息「Dear Friend」會被分成 Normal 還是 Spam？

看答案

N：0.6 × 0.47 × 0.29 ≈ 0.08

S：0.4 × 0.29 × 0.14 ≈ 0.016

0.08 > 0.016 → Normal。兩者只是「正比於」後驗機率，分母相同所以可以直接比。

p.37–44

簡答Naive Bayes 的「naive」指的是什麼假設？它有哪兩個缺點？

看答案

假設：features are conditionally independent given the class，所以可以把各個 P(feature|class) 直接相乘。

  • Zero-frequency problem：某個值在某類的訓練資料中沒出現過 → 機率為 0 → 整個乘積變 0。（常見解法：Laplace smoothing，每個計數加 1）
  • Independence assumption：現實中特徵很少真正獨立。

p.45–46

選擇把分類的 threshold 往上調高，通常會？

  1. precision ↑、recall ↑
  2. precision ↑、recall ↓
  3. precision ↓、recall ↑
  4. 兩者都不變
看答案

B。標準變嚴格 → 誤報少（FP↓），但漏掉的變多（FN↑）。

p.63

簡答ROC 曲線的兩個軸各是什麼？AUC = 1 和 AUC = 0.5 各代表什麼？

看答案

Y 軸：TPR（= recall）；X 軸：FPR（誤報率 = FP/(FP+TN)）。每個點對應一個 threshold，曲線越靠左上越好。

AUC = 1：完美分類器。AUC = 0.5：跟亂猜一樣（對角線）。AUC 跟選哪個 threshold 無關。

計算Training set 有 1000 筆。一個 epoch 裡，batch GD、mini-batch GD（batch size = 100）、SGD 各會更新幾次參數？

看答案

Batch GD：1 次；Mini-batch：10 次；SGD：1000 次。

p.22、26–29

簡答比較 batch GD 和 SGD 的優缺點。SGD 為什麼最後停不在最低點？怎麼解決？

看答案
  • Batch GD：每一步用全部資料，路徑平穩，但資料大時很慢。
  • SGD：每一步只用 1 筆，很快、能處理很大的資料集，比較有機會跳出 local minimum；但 cost 會上下跳動。
  • 到了最低點附近還會一直跳，結果「good, but not optimal」。解法：逐步降低 learning rate（learning schedule）。
  • Mini-batch：折衷，還能用 GPU 做矩陣運算加速。

p.26–30

選擇Learning rate 設得太大，最可能發生什麼事？

  1. 收斂得很慢
  2. 可能永遠不會收斂
  3. 一定找到 global minimum
  4. 變成 underfit
看答案

B。太小則是收斂很慢（A）。

p.18–19

簡答Learning curve 中，training error 和 validation error 都很高、而且很接近，這是什麼狀況？增加訓練資料有用嗎？

看答案

Underfit。加資料沒用，要換更複雜的模型。

對比：training error 低、validation error 高、中間有缺口 → overfit，加資料有幫助。

p.34–35

簡答Bias 和 variance 各是什麼？跟模型複雜度有什麼關係？

看答案
  • Bias：來自錯誤的假設（例如把二次的資料當線性），high bias → underfit。
  • Variance：對 training data 的小變動很敏感，high variance → overfit。
  • 模型越複雜 → bias ↓、variance ↑；總誤差在中間某個複雜度最低。

p.36–37

簡答Ridge 和 Lasso 差在哪？哪一個可以做 feature selection？α 很大會怎樣？

看答案
  • Ridge：L2 penalty（權重平方和），讓所有權重變小，但不會剛好變 0。
  • Lasso：L1 penalty（權重絕對值和），會把不重要特徵的權重壓成 0 → feature selection。
  • α = 0 就是一般的 linear regression；α 很大 → 權重都趨近 0 → 變成一條水平線（underfit）。
  • 不知道選哪個時，Ridge 是好的起點；知道只有少數特徵重要時用 Lasso；Elastic net 介於兩者之間。

p.39–41、47–52

簡答Feature scaling 為什麼重要？為什麼只能用 training set 來 fit scaler？

看答案
  • 特徵的數值範圍差很多時，會影響模型表現，也會讓 gradient descent 收斂很慢。
  • 只用 training set 算 mean/std（或 min/max），再用同一組數字去轉換 training 和 test：test set 要模擬「沒看過的資料」，用全部資料 fit 等於偷看了 test（data leakage），分數會太樂觀。
  • 做 regularization 前也要先 scale。

p.42–46

簡答什麼是 early stopping？

看答案

一種簡單的 regularization：訓練時一直監看 validation error，一旦它不再下降、開始上升，就停止訓練，避免 overfit。

p.53

C3 SVM

簡答Maximal margin classifier 是什麼？它最大的缺點是什麼？

看答案

選 margin（threshold 到最近資料點的距離）最大的那條 threshold。缺點：對 outlier 非常敏感，一個 outlier 就能把 threshold 拉過去。

p.7–12

簡答Soft margin 和 maximal margin 在 bias/variance 上有什麼差別？soft margin 的寬度怎麼決定？

看答案

Maximal margin：training data 全分對 → low bias，但對資料很敏感 → high variance。

Soft margin：容許部分分錯 → bias 稍高，但 variance 低很多，新資料表現較好。寬度用 cross validation 決定。

p.15–17

選擇把 SVM 的 C 調大，會怎樣？

  1. margin 變大、support vector 變多
  2. margin 變小、support vector 變少，比較容易 overfit
  3. margin 不變
  4. 模型變得比較不容易 overfit
看答案

B。C 是分錯的代價（cost），越大越不容許分錯，接近 hard margin。

p.19

簡答什麼是 support vector？為什麼說「only the support vectors matter」是優點？

看答案

落在 margin 邊緣上或 margin 裡面的資料點。決策只由它們決定，遠離邊界的點不影響結果，所以模型很精簡（不像 KNN 要存全部資料）。

p.18、43

簡答什麼是 kernel trick？為什麼 SVM 要用它？

看答案

SVM 分類只需要點和點之間的內積。Kernel 可以直接從原本的資料算出「轉到高維度後的內積」，不用真的把資料轉到高維度，省下大量運算（RBF 甚至對應到無限維度）。這讓 SVM 能畫出彎曲的邊界。

p.28–36

選擇RBF kernel 的 γ 設得很大，最可能？

  1. 邊界很平滑，underfit
  2. 每個點的影響範圍很小，邊界很彎曲，overfit
  3. 變成 linear SVM
  4. 訓練不會收斂
看答案

B。RBF 像加權的 KNN，γ 控制影響力隨距離衰減多快。γ 小 → 邊界平滑，可能 underfit。

p.38–40

簡答Polynomial kernel 的 r 和 d 怎麼選？

看答案

試不同的組合，用 cross validation 挑最好的。

p.36

簡答列出 SVM 的缺點（至少三個）。

看答案
  • 大資料集訓練很慢（要比較每一對訓練點，資料加倍、配對數約變四倍）
  • 需要仔細調參數（kernel、r、d、γ、ε）
  • 用 non-linear kernel 時很難解釋（沒有每個原始特徵的權重）
  • 沒有直接輸出機率，只有分數 g(x)

p.44

簡答為什麼 SVM 在「特徵多、樣本少」的資料（例如文字、基因資料）上表現好？

看答案

這種情況下，能把 training data 完美分開的邊界非常多，很容易挑到一條擦邊的（overfit）。SVM 固定挑 margin 最大的那一條，留的緩衝最多，對新資料比較穩。

p.43

C4 決策樹

計算用某個特徵切開後：左邊 leaf 有 3 人喜歡、1 人不喜歡；右邊 leaf 有 0 人喜歡、3 人不喜歡。求 (a) 左 leaf 的 Gini (b) 右 leaf 的 Gini (c) 加權總 Gini。

看答案

(a) 1 − (3/4)² − (1/4)² = 1 − 9/16 − 1/16 = 0.375

(b) 1 − 0² − 1² = 0（純的 leaf）

(c) 4/7 × 0.375 + 3/7 × 0 ≈ 0.214

p.19–24

計算一個 leaf 裡 2 人喜歡、2 人不喜歡，Gini 是多少？這是 Gini 的最大值還是最小值（兩類的情況）？

看答案

1 − (1/2)² − (1/2)² = 0.5，兩類時的最大值（最不純）。最小值是 0（純的）。

簡答數值特徵（例如 Age）要怎麼找最佳切點？

看答案
  1. 把 Age 由小到大排序
  2. 取相鄰兩值的平均當候選切點
  3. 每個候選切點算 Gini（分類樹）或 SSR（迴歸樹），選最低的

p.26–30

簡答怎麼決定誰當 root？Regression tree 的 leaf 輸出什麼？

看答案

每個特徵都算出它最好的切法的 Gini（或 SSR），最低的那個特徵當 root。

Regression tree 的 leaf 輸出落在該 leaf 的樣本的平均值，選切點用 SSR（sum of squared residuals）。

p.31、45–57、68

簡答決策樹怎麼防止 overfit？這些設定要怎麼選？

看答案

Pruning、限制每個 leaf 的最少樣本數、限制最大深度或 leaf 數量（regularization hyperparameters）。用 cross validation／grid search 挑最好的組合。

p.39–40、74

簡答決策樹的優點和缺點各舉兩個。

看答案

優點：自動從資料找切點（不用手動加多項式特徵）、不受 feature scale 影響、樹淺時很好解釋（if-then 規則）。

缺點：容易 overfit（high variance）、對特徵空間的旋轉敏感（切線一定平行座標軸，斜線邊界會變成階梯）、greedy 地選切點，不一定是全域最佳。

p.75–77

選擇「決策樹的切法是 greedy 的」是什麼意思？

  1. 它會用掉所有特徵
  2. 每一步都選當下看起來最好的切法，之前的切法不會回頭修改，所以最後的樹不一定最好
  3. 它會一直切到每個 leaf 都純為止
  4. 它只用一個特徵
看答案

B。

C5 Ensemble Learning

計算三個分類器對類別 1/2/3 的機率：C1 = [0.3, 0.4, 0.3]、C2 = [0.3, 0.5, 0.2]、C3 = [0.1, 0.2, 0.7]。Hard voting 和 soft voting 各預測哪一類？

看答案

Hard：C1→2、C2→2、C3→3 → 類別 2（2 票）。

Soft：平均 [0.23, 0.37, 0.40] → 類別 3。

Soft voting 會考慮每一票有多確定，通常表現比較好；但每個分類器都要能輸出機率。

p.11、18

簡答1000 個準確率只有 51% 的分類器投票，理論上可以到約 75%。這個效果成立的前提是什麼？現實中為什麼會打折？

看答案

前提：分類器之間要互相獨立、犯的錯不一樣。現實中它們常用同一份資料訓練，容易犯同樣的錯，所以效果會打折。這也是為什麼要用 bagging、random patches 等方法增加多樣性。

p.12–17、19

簡答Bagging 和 pasting 差在哪？哪個通常比較好，為什麼？

看答案

Bagging：取後放回；Pasting：取後不放回。

Bagging 的子集差異較大 → bias 稍高，但 predictor 之間比較不相關 → variance 降更多。整體通常 bagging 比較好。

p.20、26

簡答什麼是 out-of-bag (OOB) evaluation？大約多少比例的資料是 OOB？

看答案

Bagging 時，每個 predictor 平均只抽到約 63% 的訓練資料，剩下約 37% 沒被抽到的就是 OOB，可以直接拿來當驗證資料，不用另外切 validation set。注意每個 predictor 的 OOB 不一樣。

p.27–28

選擇「保留全部訓練樣本，但每個 predictor 只隨機用一部分特徵」叫做？

  1. Random patches
  2. Random subspaces
  3. Pasting
  4. Boosting
看答案

B。樣本和特徵都抽樣 → random patches。抽樣特徵會讓多樣性更高：bias 高一點、variance 更低。

p.29–31

簡答Random forest 的建立步驟。

看答案
  1. 隨機抽 n 筆資料（bagging 或 pasting）
  2. 用這些資料訓練一棵決策樹，每個節點隨機挑 d 個特徵來找切法
  3. 重複 1–2 建很多棵樹
  4. 所有樹投票（多數決）

p.33–34

簡答Random forest 和 AdaBoost 有哪三個差別？

看答案
Random forestAdaBoost
樹完整的樹，深度不一stump（深度 = 1）
投票每棵樹一票、權重一樣加權投票（amount of say）
訓練平行、各自獨立依序，每棵修正前一棵

p.38–40

簡答AdaBoost 每一輪如何處理 sample weight？最後怎麼預測？

看答案

一開始權重都一樣（1/n）。每訓練完一個 stump，被分錯的樣本權重變大、分對的變小（再正規化成總和 1），下一個 stump 就會專注在難的樣本上。每個 stump 依準確度得到 amount of say，最後加權投票。

缺點：依序訓練，不能平行化，擴展性不如 bagging。

p.37、41–43

簡答Gradient boosting 的步驟？它跟 AdaBoost 最主要的差別是什麼？learning rate 的用途？

看答案
  1. 先做第一個猜測（例如平均值）
  2. 算 pseudo-residuals（真實值 − 預測值）
  3. 訓練一棵迴歸樹去預測這些 residuals（限制 leaf 數量，leaf 輸出 residual 平均）
  4. 新預測 = 舊預測 + learning rate × 新樹的輸出，再算新的 residuals
  5. 重複，直到達到樹的數量上限或不再明顯進步

差別：AdaBoost 調整樣本權重；gradient boosting 讓新的樹去擬合前一個模型的殘差。

Learning rate（0–1）：每次只往正確方向走一小步，避免 overfit，降低 variance。

p.44–49

C6 降維

簡答什麼是 curse of dimensionality？為什麼維度高容易 overfit？

看答案

維度越高，空間越稀疏（sparse），點和點之間都離得很遠，新資料可能離任何訓練資料都很遠，預測不可靠（KNN 的「最近鄰居」其實也不近）。模型在大部分空間沒受到約束，容易去擬合雜訊 → overfit。

想靠增加資料讓空間變密，所需資料量會隨維度指數成長，不實際。

p.2、8–10

簡答什麼是 Hughes phenomenon？

看答案

訓練資料量固定時，特徵數增加，分類器表現先變好，到最佳特徵數後再增加特徵，表現反而變差。

p.7

簡答降維的好處和壞處各是什麼？

看答案

好處：訓練變快、可以降到 2D/3D 做視覺化（看出群聚）、有時能濾掉雜訊。

壞處：會損失資訊（像 JPEG 壓縮），表現可能略差；流程變複雜、較難維護。建議先用原始資料訓練，太慢再考慮降維。

p.3–5、17

簡答Projection 和 manifold learning 差在哪？用 Swiss roll 說明 projection 的問題。

看答案

Projection 是線性的：把資料投影到低維的平面上。Manifold learning 是非線性的：假設資料位在一個彎曲的低維流形上。

Swiss roll 是捲起來的 2D 流形。直接投影（例如丟掉 x3）會把不同層壓在一起；我們真正想要的是把它攤開。

p.11–16

簡答PCA 怎麼選投影的軸？principal components 之間有什麼關係？

看答案

選能保留最大 variance 的軸（損失的資訊最少）。第 1 個 PC 保留最多 variance；第 i+1 個 PC 跟前面所有 PC 正交，保留剩下最多的 variance。投影後不同 PC 上的值彼此線性不相關。

p.18–21

計算PCA 算出的 eigenvalue 由大到小是 4.5、3、1.5、0.5、0.5。PC1 的 explained variance ratio 是多少？要保留至少 95% 的 variance，k 要選多少？

看答案

總和 = 10。PC1 = 4.5/10 = 45%。

累積：45% → 75% → 90% → 95%，所以 k = 4。

Eigenvalue = 資料在該 PC 方向上的 variance；eigenvector = 那個 PC 的方向。

p.24–26

簡答什麼是 reconstruction error？MNIST 用 PCA 保留 95% variance 會剩幾維？

看答案

把降維後的資料用反轉換解壓回原本的維度，跟原始資料之間的平均平方距離。因為投影時丟掉了一些資訊，所以解壓回來不會完全一樣。

MNIST 從 784 維剩約 154 維，不到原本的 20%。

p.28–29

簡答t-SNE 保留的是什麼？低維空間為什麼用 t-distribution 而不是 Gaussian？

看答案

保留 local relationships：高維中相近的點，降維後也相近；遠的點不會被放在一起（但確切距離不保留）。

流程：高維用 Gaussian 把距離轉成相似度機率 → 低維隨機放點，用 t-distribution 算相似度 → 用 gradient descent 反覆調整，讓兩個相似度矩陣越像越好。

用 t-distribution 是因為 crowding problem：低維空間放不下那麼多等距的點，非鄰居會被擠在一起。t-distribution 的尾巴比較厚，可以把不相鄰的點推得更遠，群聚就能分得清楚。

p.30–40

選擇你有一個很大的資料集，想要快速、可重現、可解釋的降維結果，應該用？

  1. PCA
  2. t-SNE
看答案

A。PCA：線性、保留全域結構、快、穩定、可解釋。t-SNE：非線性、保留局部結構、適合視覺化群聚，但慢、不穩定（受隨機性影響）、難解釋。

p.41

簡答Dimensionality reduction 和 feature selection 差在哪？

看答案

降維：從原始特徵創造新特徵（例如 PC），可解釋性降低，常用於視覺化、降雜訊。

Feature selection：保留原始特徵的子集，可解釋性保留，容易套用到新資料，常同時提升速度和表現、減少 overfit（例如 Lasso）。

p.42
